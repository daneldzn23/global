# Kraken

## Why it's a reference

Kraken sells to the same kind of persona split Nelogica does (retail
trader vs. institutional/pro), on a single marketing site, without it
feeling like two different products bolted together. Useful precedent
for the persona-routed CTA structure ("I'm a trader" / "For brokers" /
"For prop firms") already locked in V1.4's copy.

## What to steal

- **Persona-routed navigation/CTAs treated as a real product decision,
  not an afterthought row of buttons** — distinct visual weight and
  placement per audience, so "Pro / Institutional" doesn't read like a
  secondary footnote to the retail path.
- **Real order-book and price-ticker UI as hero/section imagery** —
  live-feeling numbers, not placeholder data or a diagonal-stripe
  "preview coming" block (the exact V1.4 pattern DESIGN.md flags).
- **Restrained color use**: a near-monochrome dark base with a single
  accent color doing all the work (their purple ≈ Nelogica's
  `--blue`/`--tick`), instead of multiple competing gradients per
  section.
- **Trust/compliance signals presented as plain facts** (regulatory
  badges, security certifications, uptime) in a quiet strip — parallel
  to how Nelogica's partner logos (CME, Nasdaq, NYSE, Itaú, BTG...)
  should carry authority per DESIGN.md's "confidence without hype."

## What NOT to copy

- Kraken's retail-facing pages use fairly aggressive conversion
  copy ("Get started," urgency framing) — DESIGN.md explicitly wants
  to avoid "SaaS-cliché urgency language or unearned superlatives."
  Borrow the layout logic, not the tone.

## Where to look

- Kraken Pro landing page and the institutional/OTC desk page — the
  clearest examples of persona-split without visual inconsistency.
