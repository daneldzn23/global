# Moodboard References

Design references for the visual redesign described in `DESIGN.md`.
Each file names what to steal from that company's design and — just as
important — what not to copy, so these stay actionable instead of
generic "good design" praise.

- [tradingview.md](tradingview.md) — dense chart data as hero imagery
- [kraken.md](kraken.md) — persona-routed layout (retail vs. institutional)
- [apple.md](apple.md) — device mockup staging/lighting craft
- [stripe.md](stripe.md) — real UI embedded as proof, restrained gradients
- [coinbase.md](coinbase.md) — institutional trust signals without hype
- [linear.md](linear.md) — counter-example to every AI-slop pattern DESIGN.md flags

None of these are stylistic templates to clone wholesale — DESIGN.md's
brand tokens (color/type) and locked copy stay fixed regardless of
which reference a given section draws from.
