# TradingView

## Why it's a reference

The closest same-category product to Nelogica's own platforms
(BlackArrow/Bookmap/Profit are charting/execution tools — TradingView
*is* a charting tool). It's the proof that dense financial data can be
the hero image, not a decoration around one. Directly supports
DESIGN.md's "show, don't tell" and "precision reads as craft"
principles.

## What to steal

- **Real chart screenshots as hero imagery**, always mid-interaction
  (drawing tools active, indicators overlaid, watchlist populated) —
  never an empty/idle chart. This is the direct antidote to V1.4's
  stock-photo-of-a-trader hero.
- **Dark-mode-first product chrome** that matches Nelogica's own
  `--ink`/`--surface` palette family almost natively — dark UI reading
  as "trading software," not "SaaS dashboard."
- **Layered/staggered screenshot compositions**: multiple chart panels
  overlapping at slight offsets with soft shadows, instead of one
  flat, centered screenshot in a device frame.
- **Candlestick/line chart motifs used as background texture** in
  low-opacity — legible market-data patterns instead of abstract blobs
  or gradient mesh.
- Feature sections built around **one annotated screenshot with
  callout labels pointing at real UI elements**, rather than an
  icon + heading + paragraph card grid.

## What NOT to copy

- TradingView's marketing site leans consumer/prosumer (freemium,
  social feed, "join millions of traders") — Nelogica's tone per
  DESIGN.md is B2B/institutional (brokers, prop firms, real partner
  logos), so skip the social-proof-via-user-count angle and any
  gamified/community framing.

## Where to look

- Homepage hero and the "Charting" / "Screener" product pages —
  specifically how each product page uses one large annotated
  screenshot instead of a features grid.
