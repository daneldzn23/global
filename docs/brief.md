# Product Brief

## Goal

The global (English-language, `nelogica.com`) counterpart to Nelogica's
Brazil-market site (`nelogica.com.br`) — an institutional page presenting
Nelogica as an international trading-technology company. Unlike a pure
brand-only page, it does carry real conversion paths: routing visitors
by persona (trader / broker / prop firm) toward contact, and a careers
CTA. It is not a product-marketing deep-dive site — no pricing, no
per-product funnels.

Corrects an earlier assumption in this doc: v1 is **not** CTA-free. See
`reference/nelogica-global-V1.4.html` for the approved reference (copy
is final, reused 1:1 — see `product-requirements.md`).

## Audience

External, international audience: traders, brokers, and prop firms
evaluating Nelogica as an infrastructure/technology provider, plus
prospective engineering hires (careers section). Distinct from the
Brazil-focused, Portuguese-language nelogica.com.br.

## Scope

**V1: single-page, sectioned (see product-requirements.md for the full
list and locked copy).** Structure and copy come from
`reference/nelogica-global-V1.4.html`; what's being redone is the visual
execution, not the content or IA.

Out of scope for v1: per-product marketing pages, pricing, login/account
areas, blog/news, multi-language routing beyond the existing EN
(`nelogica.com`) / PT-BR (`nelogica.com.br`) split already implied by the
`hreflang` tags in V1.4.
